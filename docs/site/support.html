XTermX Support

Contact C. Cassel at cassel@cassel.us for help with XTermX on iPhone, iPad, Apple Watch, Mac or Linux.

Include your app version, device/OS version, what you expected and the steps to reproduce. Use fictional terminal text in examples. Do not send pairing links, QR secrets, passwords, SSH private keys or unrelated terminal history.

Connect to your host

  1. Run XTermX on your Mac or Linux machine.
  2. On the Mac, open Remote access and enable it.
  3. On iPhone or iPad, choose Scan pairing code or Paste pairing link.
  4. Keep both devices on a network where the host is reachable. For access away from home, use a network/VPN you manage.

An SSH connection requires a reachable SSH server and your own login credentials. XTermX does not provide hosted servers or a VPN.

Files and videos

Enable Receive files from devices on the host before attaching a file. Compatible hosts accept files up to 64 MB. The transfer places a file on your host; inserting its path does not automatically make the program in the terminal understand that file type.

Devices and permissions

A remembered offline device is not an active connection. Pane access can be view and control, view only, or private. If a connection was lost, check your host, network and permissions.

To revoke existing pairings, use Forget all devices on the host and pair trusted devices again.

Report a problem

Email cassel@cassel.us. For public-core bugs that contain no private information, you may also open a GitHub issue. For a security concern, use email first.
